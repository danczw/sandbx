**Nothing a command can reach changes in this release: no flag, no policy, no
enforcement path.** tokio moves to 1.53.3 for RUSTSEC-2026-0386. Everything else is
the first phase of moving the workspace onto the Google Rust style guide (#328),
which is groundwork for splitting `sandbx-core` later and carries no behavioural
change of its own. `SECURITY.md`'s claims, non-claims and known weaknesses are
unchanged.

**One `context/` file was renamed and three were deleted**, so an external link into
any of them is now dead. `decision-axis-table.md` is `decision-policy.md`, matching
the title it already had; every anchor is unchanged and `SECURITY.md`'s five links
to it were re-pointed. `guide-naming.md`, `guide-code-comments.md` and
`guide-module-layout.md` are gone, replaced by the Google guide plus
`guide-testing.md` for what that guide leaves to the project — what a test has to
assert, where it lives, and a fifty-character ceiling on its name. The departures
sandbx takes from the guide are recorded in `decision-google-style.md`, including
the one still undecided, and `CLAUDE.md` now states the comment pass outright
rather than citing a guide for it.

**Two CI gates are new, and either can fail a pull request that changes no
behaviour.** cargo-deny now checks which workspace crate may depend on which, so an
unrecorded edge between crates fails `audit`. And every crate has a committed
public-API baseline at `crates/<crate>/public-api.txt`, which `api-diff` regenerates
and fails on when stale — so a `pub(crate)` widened to `pub` arrives as an added
line in the pull request's own diff instead of a line in a log nobody opened.
Regenerate with `.github/scripts/public-api.sh`, which needs the pinned nightly it
names: rustdoc JSON is nightly-only, while the build and the tests stay on stable.
