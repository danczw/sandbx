**A run with no path flag now grants read and write on the working directory**
(#150); any of `--allow-read`, `--allow-write` or `--allow-exec` replaces that
default rather than adding to it. It is refused for `/`, `$HOME`, a directory
holding it, and one overlapping a system executable path — but write on a
project tree is write on `.git/hooks`, which runs outside the sandbox.

**`--allow-network` now takes TCP ports** (#151), and a port list denies UDP and
raw sockets, so names stop resolving: such a run needs an IP, or a resolver it
can reach over TCP. Nor is a port list uniformly narrower than no network —
narrower on remote ports, wider on what is local. The trail writes `network` as
a string beside a `network_ports` count, and closes each run with an exit or
failure record (#158). `Grants::policy()` returns a `Result`.
