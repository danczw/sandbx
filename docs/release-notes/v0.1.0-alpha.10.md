**`agent-run` now refuses `write`, `edit` and `bash` unless you ask for them**
(#106): a gate decides every tool call before it runs, and without
`--allow-tool` only the four read-only tools do. Name one to lift the refusal —
repeatable — or pass the flag bare for all seven; an unknown name is refused
rather than quietly approving nothing. A refusal reaches the model as an errored
`tool_result`, so it can retry a tool you did allow and the turn still exits 0.

**The decision is per tool per run, not per call** (#165). Once `--allow-tool
bash` is passed, every command the model asks for that turn runs, including one
a prompt injection induced; the sandbox policy is still all that bounds where an
approved call reaches. stderr carries the gate's verdict and nothing after it, so
a call it approved and the policy then refused reads there as one that ran (#169).
