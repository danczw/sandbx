**A `$HOME` that names no home directory is now refused rather than trusted**
(#154, #162): one resolving to nothing, a non-directory, or where other people's
homes live — `/`, `/home`, `/var/home`, though `/root` is still root's. It bites
where the working directory is itself home-shaped — a direct child of `/home`,
`/Users`, `/var/home` or `/root` — which alpha.8 handed read and write; pass the
path flags instead. Elsewhere an unusable `$HOME` still derives a default.

**`--dns-over-tcp` lets a name resolve under a port allowlist** (#147), by asking
glibc's stub resolver for TCP — not musl's, and not enforced. It allowlists no
port itself, so pass `--allow-network 53` and `--allow-read /etc` too; with
`--allow-env RES_OPTIONS` it is refused. A refusal inside the helper now closes
the trail as `failed reason=<label>`, not `exited code=1` (#157, #160).
