**A `$HOME` that names no home directory is now refused rather than trusted**
(#154, #162): one resolving to nothing, a non-directory, or where other people's
homes live — `/`, `/home`, `/var/home`, though `/root` is still root's. Under
`HOME=/` a run with no path flag took read and write on the working directory in
alpha.8 and now refuses, naming what it rejected; pass the path flags instead.

**`--dns-over-tcp` lets a name resolve under a port allowlist** (#147), by
asking glibc's stub resolver for TCP — not musl's, and not enforced. It
allowlists no port itself, so pass `--allow-network 53` and `--allow-read /etc`
too; with `--allow-env RES_OPTIONS` it is refused. A refusal inside the sandbox
helper now closes the trail as `failed reason=<label>`, not `exited code=1`
(#157, #160).
