**`agent-run --session` carries a conversation across runs** (#108). Bare starts one
and prints its id; that id resumes it. The transcript is plaintext JSONL under
`$XDG_STATE_HOME/sandbx/sessions`, `0600` in a `0700` directory, holding whatever a
tool read into the conversation; nothing expires or redacts it. One another user can
write is refused, one they can only read resumes and says so — but a policy granting
write over the session root lets a turn rewrite the next turn's history (#173).

**`--pin-sha256` names bytes where an exec grant names only a path** (#146).
`--allow-exec` runs whatever is at that path at `execve` time, so paired with write on
the same tree a command can pick its own binary; a digest mismatch refuses the run as
`failed reason=pin_mismatch` before anything executes. It pins the entry point alone —
a pinned `/usr/bin/python3` is still arbitrary code — and nothing changes without it.
