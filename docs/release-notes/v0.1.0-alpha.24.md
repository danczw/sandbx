**Nothing breaks for the CLI, and a stopped `tui` turn is now kept.** A turn
stopped on the screen, by a keypress or a hung-up terminal, stores the prompt
and every round it finished under `--session`, and loses the round it stopped in
whole: a tool call already running still finishes, and the transcript records
neither its effect nor its result. A stop before the first round finishes still
stores nothing (#271). Transcripts stay at version 1, and the `turn` line gains
the stops `interrupted` and `hung_up`, which an older build reads as no stop
recorded. A turn out of rounds under `tui` now gets the wrap-up round
`agent-run` sends, one more request with no tool, and `--no-wrap-up`, parsed and
ignored there until now, is honoured (#232).

**A granted path that is not UTF-8 is enforced as named.** Its bytes reached the
helper as a U+FFFD spelling, so the kernel refused the ruleset and the command
never ran; they now cross as they are (#495). Embedders: `HelperArgs::encode`
returns, `HelperArgs::decode` takes and `CommandLine::argv` holds `OsString`,
and a hand-invoked `sandbx-helper` refuses a non-UTF-8 token anywhere but a
granted path.

**The six `--help` pages with an example print it as written**, not joined onto
one line, and wrap at about 85 columns rather than the terminal's width (#498).
A resumed prompt is now a compaction cut point, though no flag turns compaction
on yet (#208, #302), and `SECURITY.md` names the one `#[allow]` on the spawn
lint, in the dev-only `sandbx-helper-fixture`.
