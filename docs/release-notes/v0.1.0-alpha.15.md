**A command with unix sockets off could reach a host socket no grant named, and that route is
closed** (#267). `socketpair(2)` hands back an `AF_UNIX` descriptor without calling `socket(2)`, so
the denial the unix-socket axis installs never saw it, and a datagram pair is connectionless — an
ungated `connect` re-aims one half at any pathname socket. Measured on 6.18 at Landlock ABI V8: a
sandboxed `perl` with network denied delivered to a host socket, while the audit record read
`unix_sockets=false`. One-way and datagram-only, the netns holding the return path, so
`docker.sock`, an ssh-agent and the session bus were never reachable this way — all three
`SOCK_STREAM` — where `/dev/log` and systemd's notify socket were. Seccomp now denies every
`socketpair(AF_UNIX)` type but `SOCK_STREAM` and `SOCK_SEQPACKET`, which are born connected and
answer `EISCONN`: **a program using a datagram socketpair for its own internal IPC now fails**
without `--allow-unix-sockets`. That flag also confers `ResolveUnix` (#259), so the first V9 kernel
does not give one all-or-nothing boolean an unannounced path condition.

**Four exit codes changed, and a caller branching on them has to be read again.** A command line
sandbx refuses exits 64, not the 2 a cut-short round earns (#265), so no exit code of a run is
reachable by mistyping a flag; `--help` and `--version` keep 0, a bare `sandbx` does not. A `tui`
turn whose terminal is destroyed ends and exits 3 instead of spinning a core forever (#264), a
finished one keeps the code it earned where a failed draw flattened every code to 1 (#257), and
ratatui's panicking restore no longer aborts at 134, losing that code and the audit trail the
screen still held (#270).

**`grep` marks what it walked and did not read** (#274): an oversized-file skip left no marker, so
a tree whose only match sat in a file over 2 MiB rendered as `no matches`. A repo-root grep will
almost always mark now, a checkout's pack files being over the cap. Its per-file size test moved
onto the handle it reads through the guard (#275), so the file measured cannot differ from the file
read and every walked file reaches the audit trail. The gutter mark gained the twenty forgeable
codepoints its own doc comment claimed (#276), and three claims were narrowed to their mechanism:
the descendant-survival carve-out (#273), the policy-visibility route, which is the supervisor's
cmdline and not the command's (#278), and three sentences of CLI long help (#277).
