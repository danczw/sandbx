**`--approve call` now works under `tui`, and compaction has a flag.** The
question that `tui` used to refuse for want of a terminal is drawn in rows under
the transcript, and one key answers it: `y` for the call, `n` to refuse it, `a`
for every later call to that tool. Keys typed before the question was drawn are
discarded, escape or ctrl-c refuses the call and ends the turn, and a screen
that cannot show the question or read keys ends the turn rather than guess. A
pane too short for the whole question shows its first and last rows, and a
resize while one waits is not redrawn until it is answered (#225, #508).
`--compact-at <TOKENS>` turns compaction on for `agent-run` and `tui`; without
it nothing is left out, and it acts only on a `--session` history (#302).

**`read` and `edit` stop at 2 MiB, whatever the file reports.** `read` returns
the head of a file up to `max_bytes`, with the truncation marker, where it used
to load the whole file first and refuse one that was not wholly UTF-8, and it
no longer hangs on `/dev/zero`; `edit` refuses a file past 2 MiB and leaves it
untouched (#493). The seccomp denylist gains `open_tree_attr`, the one call of
the descriptor mount API it did not name. It is defence in depth, as stage 2
holds no `CAP_SYS_ADMIN`, and a kernel older than 6.15 now answers `EPERM`
where it answered `ENOSYS` (#494).

**Nothing else breaks.** `rustix` is bumped to 1.1.6, which clears
RUSTSEC-2026-0486. Embedders see new public items in `sandbx-screen`,
`sandbx-tui-input` and `sandbx-tui-transcript`, and one removal from
`sandbx-cli`.
