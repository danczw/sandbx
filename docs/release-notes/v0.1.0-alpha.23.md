**`tui` ends differently, and a file tool's audit record gains a field.** When
a turn ends the screen goes without waiting for a keypress, and the transcript
is printed to stdout in its place, so the answer stays in scrollback (#224). A
terminal stderr's audit trail is still held until then, and a signal in that
window loses it, which `SECURITY.md` now states; redirected, each record is
written as it happens (#485). `allowed`, `absent` and `denied` carry `session=`
right after `decision`, `-` where there is none, so a parser keyed on field
order sees one more (#429).

**A failed run names its cause, and the gate's question spells what it shows.**
A provider error prints its source chain, so a DNS failure, a refused
connection and a rejected certificate no longer read alike, and that line is
escaped as the gate's question is (#457). Both spell `\` as `\\`, and U+2028 and
U+2029 as `\u{…}`, so a command holding a newline no longer reads like one
holding a literal `\n`, and every backslash in the question shows doubled
(#478). An `--allow-dns` name that resolved to nothing is looked up once more
after 100ms, so a host rewriting `/etc/hosts` at run start no longer drops it
for the run (#472).

**Transcripts stay at version 1, and resume says why a turn ended.** The `turn`
line records its stop, so a gate abort is no longer resumed as a round limit, a
capped turn the wrap-up answered reads `summarised`, and a turn recorded before
this release hedges; an older build ignores the field (#226). Leaf modules are
named after their primary item (#449), and `deny.toml` refuses reqwest outside
`sandbx-anthropic` and a production edge into a fixture crate (#456, #465).
