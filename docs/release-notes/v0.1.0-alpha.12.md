**The write path concealed nothing before this** (#183). A write to a missing parent
answered ENOENT where an unwritable one answered EACCES, for any path on the host,
unrecorded either way — an oracle a prompt-injected model could map a machine with.
Both now conceal alike, and that refusal is recorded. `agent-run` now refuses
`--allow-env ANTHROPIC_API_KEY`, where `sandbox-run` still grants it (#41).

**`decision=` now records the access, not the verdict** (#180, #182, #187). A seventh
value, `absent`, names a path that denotes nothing inside a granted root; `allowed` waits
for the open, walk or listing, so a trail no longer counts files nothing opened. A turn
out of rounds exits 2 with the bound on stderr, not 1, and `--max-rounds` moves a cap the
session no longer holds (#178, #188): `TurnError::RoundLimit` is gone, `TurnOutcome` gained
`stop`. Every run's system prompt names its roots, `--system` appended.
