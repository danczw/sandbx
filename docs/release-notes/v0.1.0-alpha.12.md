**A tool call for a path that names nothing inside a root you granted no longer
emits `decision="denied"`** (#180), so a pipeline counting tool refusals will see
fewer lines for the same agent behaviour. The model gets a failure carrying "could
not find" instead of "refused by the sandbox policy", and so retries the filename
rather than asking for a wider grant. Outside every granted root absence and refusal
stay indistinguishable, and an in-grant EACCES or `ELOOP` is still a `denied`.

**The write path concealed nothing before this.** A write to a missing parent answered
ENOENT where an existing unwritable one answered EACCES, for any path on the host and
with no audit record either way — a filesystem oracle a prompt-injected model could map
a machine with. Both paths now decide concealment the same way, and the one `write`
refusal that recorded nothing records it (#183).
