**The write path concealed nothing before this** (#183). A write to a missing parent
answered ENOENT where an unwritable one answered EACCES, for any path on the host,
unrecorded either way — an oracle a prompt-injected model could map a machine with.
Both now conceal alike, and that refusal is recorded. `agent-run` now refuses
`--allow-env ANTHROPIC_API_KEY`, where `sandbox-run` still grants it (#41).

**A path naming nothing inside a granted root no longer emits `decision="denied"`**
(#180), so a pipeline counting refusals sees fewer lines, same behaviour; no
`decision=` value is added or removed. A turn out of rounds exits 2 with its text on
stdout and the bound on stderr, not 1; `--max-rounds` moves the cap, and the session
holds none of it (#178, #188). Every run sends a system prompt naming its roots,
`--system` appended; `TurnError::RoundLimit` is gone, `TurnOutcome` gained `stop`.
