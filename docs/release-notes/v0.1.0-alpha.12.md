**The write path concealed nothing before this** (#183). A write to a missing parent
answered ENOENT where an unwritable one answered EACCES, for any path on the host,
unrecorded either way — an oracle a prompt-injected model could map a machine with.
Both now conceal alike, and that refusal is recorded. `agent-run` now refuses
`--allow-env ANTHROPIC_API_KEY`, where `sandbox-run` still grants it (#41).

**`decision=` now records the access, not the verdict** (#180, #182, #187). A seventh
value, `absent`, names a path that denotes nothing inside a granted root; `allowed` waits
for the open, walk or listing, so a trail no longer counts files nothing opened. A `bash`
call refused by a program pin now reads as a refusal, not a failure: the model is told
"refused by the sandbox policy" and stops retrying the program. Every other
helper-reported refusal — a Landlock ruleset the kernel would not take, a filter that
would not install, a malformed argv — stays a failure, but one whose subject names the
sandbox rather than the command, so it is no longer indistinguishable from a command that
exited 1 (#185).

**A turn out of rounds exits 2, not 1**, and is then asked once more with no tool call
allowed, so stdout gets a summary and `--session` stores the turn rather than refusing
it; `--no-wrap-up` opts out (#178, #189). A run that approves fewer than all seven tools
now has them named in its system prompt beside its roots, so a refused tool no longer
costs a round; a run approving every tool names none, and `--system` is appended to
either (#197). Embedding the crates directly: `TurnError::RoundLimit` is gone and
`TurnOutcome` carries `stop` in its place, and `Turn` and `MessagesRequest` each gained a
`tool_choice` field, so a struct literal over either needs one more line.
