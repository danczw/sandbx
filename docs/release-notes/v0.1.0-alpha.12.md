**`--allow-read ~` and `--allow-read /` are now refused** (#173, #184). A path grant
reaching sandbx's own session directory or credential file is refused on both run
subcommands, on every host and whatever is stored there — both roots derive under `$HOME`,
and one turn that can rewrite a transcript chooses what the next is told it said. Grant
the trees the command needs instead; there is no override flag. sandbx also clears its
dumpable flag at startup, so a command granted `/proc` cannot read an exported key out of
the harness's `environ` (#192). Separately, a tool write to a missing parent answered
ENOENT where an unwritable one answered EACCES, for any path on the host and unrecorded
either way — an oracle a prompt-injected model could map a machine with; both now conceal
alike, and the refusal is recorded (#183). `agent-run` refuses
`--allow-env ANTHROPIC_API_KEY`, where `sandbox-run` still grants it (#41).

**`decision=` now records the access, not the verdict** (#180, #182, #187). A seventh
value, `absent`, names a path that denotes nothing inside a granted root; `allowed` waits
for the open, walk or listing, so a trail no longer counts files nothing opened. A `bash`
call refused by a program pin now reads to the model as a refusal, not a failure — it is
told "refused by the sandbox policy" — and stops retrying the program; every other
helper-reported refusal, a Landlock ruleset the kernel would not take or a filter that
would not install or a malformed argv, stays a failure, but one whose subject names the
sandbox rather than the command, so it is no longer indistinguishable from a command that
exited 1 (#185).

**A turn out of rounds exits 2, not 1**, and is then asked once more with no tool call
allowed, so stdout gets a summary and `--session` stores the turn rather than refusing it;
`--no-wrap-up` opts out (#178, #189). A run that approves fewer than all seven tools now
has them named in its system prompt beside its roots, so a refused tool no longer costs a
round; a run approving every tool names none, and `--system` is appended to either (#197).
Embedding the crates: `TurnError::RoundLimit` is gone and `TurnOutcome` carries `stop` in
its place, `Turn` and `MessagesRequest` each gained a `tool_choice` field, and
`FsGuard::read_dir` is new — `ls` held a path rather than a handle.
