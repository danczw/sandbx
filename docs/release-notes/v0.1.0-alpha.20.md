**Every `.rs` file in a crate now sits directly under its `src/`, so a link or a
path citation naming one re-points.** 57 files left `command/`, `error/`,
`policy/`, the `helper/` tree, `agent/`, `anthropic/`, `wire/` and `tools/`; a
file's name is its module path joined with `_`, so `helper_ruleset_rights.rs` is
`helper::ruleset::rights` and `context/guide-repo-map.md` is the index. **No
code edit follows.** A `#[path]` on each `mod` line whose file moved keeps the
module tree, so no `use`, no `crate::` link and no `super::`-relative path
changed — which also kept it out of other crates' API baselines, those spelling
an item by its defining path, private modules included.
`docs/release-notes/*.md` keep their old paths: a shipped note describes the
tree at its tag.

**A module's unit tests are a sibling file rather than an inline block, and two
test fixtures are crates.** 54 `*_tests.rs` siblings arrived, declared
`#[cfg(test)] #[path = "…"] mod tests;`, and a `lib.rs` names its sibling after
the crate where a `main.rs` takes `main_tests.rs`. `sandbx-helper-fixture` and
`sandbx-turn-fixture` take the workspace to 28 crates, both dev-only and in
nobody's build, which `deny.toml` now states and CI checks against the real
graph. The helper one takes the binary's path as an argument: `CARGO_BIN_EXE_*`
is set only for a target of the package declaring that bin, so the `env!` the
module used could not survive the move. Seven integration-test roots stopped
declaring `mod support;`.

**Nothing widened.** Every `public-api.txt` that existed at alpha.19 is
byte-identical; the only baselines added are the two fixtures' own. That is a
claim about reachability and not about tidiness — a baseline records only `pub`
items reachable from a crate root, so each crate's full visibility multiset was
compared across the move as well, and the three `pub(super) mod tests` that a
neighbouring module reads stayed `pub(super)` rather than widening to `pub`.
