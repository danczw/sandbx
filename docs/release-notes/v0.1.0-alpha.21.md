will fail until one toolchain is installed.** Three of the four rustfmt
options the Google style guide names are nightly-only, so the fmt gate moved
to `nightly-2026-09-11` and both `.githooks/pre-commit` and CI need it:
`rustup toolchain install nightly-2026-09-11 --component rustfmt`. Both
halves also fail on a `Warning:` line, because rustfmt skips an option it
cannot set and still exits 0 — left on stable, `cargo fmt --check` reported
green having enforced none of them (#334).

the books.** 1,162 inline `std::` paths became module-qualified calls and
unqualified type names, all 49 glob imports across 45 files took explicit
item lists, and the exception that excused `use super::*` in a sibling test
module is deleted rather than re-recorded. 27 lines still spell a path out,
each for a reason the PR that left it gives. Phase 5 of #328; phases 6 and 7
remain.

`public-api.txt` baselines are byte-identical to alpha.20, and the visibility

a direct child of its crate root and the two spellings name the same set.

so blame skips them for the commit that last changed the code; GitHub honours
