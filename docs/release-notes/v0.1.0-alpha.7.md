**`sandbx agent-run` is the first thing you can type that reaches the turn
loop** (#135). A prompt in, the answer streamed to stdout, every tool call
confined by the same boundary `sandbox-run` uses. Nothing asks you before a tool
call runs, so the grants you pass are the whole of what a prompt-injected turn
can touch (#106). Needs `ANTHROPIC_API_KEY`, which no tool sees unless you pass
it to `--allow-env` — and that hands over the value in full.

**Breaking for library callers:** `SandboxError::PathNotAllowed` carries an
`Access`, because a path refusal now names the grant it lacked — "outside every
readable root" rather than "every allowed root". No CLI flag moved. The
enforcement suite now also runs against the static-musl triple that ships, on
both architectures, closing the gap `alpha.6` left open (#130).
