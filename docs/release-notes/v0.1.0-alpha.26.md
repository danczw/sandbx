**A stop under `tui` now kills a running `bash` command and keeps the round it
landed in.** Ctrl-c or escape used to leave the command running and drop the
round. Now a `bash` call is killed, a `read`, `ls`, `grep` or `find` is
abandoned on its thread, with a `grep` also stopping before its next file, and a
`write` or `edit` still finishes first, so a `write` under way lands. An
abandoned read can outlive the stop until it finishes or the process exits. With
`--session`, a stop while tools ran stores the round with every call answered: a
call that had settled keeps its output, the one stopped on is stored with its
output withheld, and one behind it as not run. A stop while the model is still
writing loses the round as before (#271). A `write` or `edit` is still waited
for by design, which is why #26 was closed.

**The screen says more while it waits.** The running call is named on a row
under the log until it settles, and a resize while a question waits redraws it
within about a tenth of a second. A key pressed in that gap still answers the
old frame (#517, #508).

**This is the first release whose archives are attested.** `gh attestation
verify` with `--signer-workflow` ties an archive to the release run that
published it, as the README shows. It says which run, not that the source is
trustworthy (#511). Nothing else breaks for a user, but `SandboxError`,
`ToolError` and `sandbx-tui-input`'s `Reply` each gain a variant, so an embedder
matching one exhaustively must add an arm. `sandbx-core` also gains `Cancel`.
